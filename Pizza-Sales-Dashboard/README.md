# Pizza Sales Dashboard

## Project Overview

This project analyzes pizza sales data to identify customer purchasing patterns and sales trends.

## Business Objective

To understand customer preferences and improve sales performance.

## Tools Used

* Power BI
* Power Query

## Dashboard Features

* Revenue Analysis
* Sales Trend Analysis
* Top Selling Pizzas
* Category Analysis
* KPI Monitoring

## Key Insights
- Total Revenue reached ₹817.86K from 21,351 orders, averaging 78 orders per day.
- Customers purchased an average of 2 pizzas per order, indicating strong multi-item buying behavior.
- Revenue was highest during the first quarter (Jan–Mar) and declined in subsequent months.
- Classic Pizza emerged as the most popular category, followed by Supreme and Veggie.
- Large (L) pizzas were the preferred size, while XXL pizzas recorded the lowest demand.
- Friday generated the highest order volume, with afternoon being the busiest ordering period.
- The Classic Deluxe Pizza was the best-selling product, followed by Hawaiian and Pepperoni Pizza.
